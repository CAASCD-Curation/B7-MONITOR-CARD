# 第三版 · 像素风格监控室

本分支根目录是团队的案例档案库网页（原始第三版）。
本目录新增内容：

- `pixel/` — 像素风格单页展厅（构建产物，可直接静态托管）
  - 无导航、无侧栏，主页面为大量倾斜悬浮的 CRT 显像管屏幕
  - 点击屏幕弹出详情窗口（不跳转），含大图与完整档案文字
  - 视觉：像素边框、点阵字体、CRT 扫描线、颗粒噪点、暗角、白框辉光
- `pixel-src/` — 上述网页的 React + Vite 源码（`npm install && npm run build` 构建）

## 本地预览

直接用浏览器打开 `pixel/index.html`，或：

```bash
cd pixel-src
npm install
npm run dev
```

## 数据

50 件档案（49 件来自策展文案 + 1 件素材补充：数据中心 NOC），
图像位于 `pixel/img/`（`thumbs/` 为像素化缩略图）。
原图缺失的「地震监测台网中心」以雪花噪点屏呈现。
