# B7-MONITOR-CARD

监控室 · 案例档案库 —— 围绕「监控 / 凝视 / 全景敞视」主题的卡片式案例展示网页,收录经典艺术档案、文学意象、形式灵感、社会素材四大类共 50 个案例,数据来源于石墨文档《监控室》协作表格。

## 🌐 在线访问

**https://miffy-1.github.io/B7-MONITOR-JianKongShi_1/**

## 功能

- 卡片式布局,每个案例含封面图、CAM 编号、分类标签、作者、年代、简介
- 分类筛选 + 关键词搜索
- 点击卡片查看完整档案
- 响应式设计,支持移动端

## 文件结构

```
index.html    # 网页主文件(数据已内嵌)
cases.json    # 结构化案例数据
images/       # 50 张案例图片
```
